# Замер скорости скачивания

Скрипт скачивает один и тот же файл 10 раз подряд. После каждой загрузки показывает, сколько байт получил и сколько времени это заняло. В конце выводит среднее время запроса, общий объём и скорость в Мбит/с.

## Как запустить

Достаточно Python 3.8 или новее. Откройте терминал в папке со скриптом и передайте ему прямую ссылку на файл по HTTP или HTTPS.

```sh
python download_speed.py "https://www.python.org/static/img/python-logo.png"
```

В Windows можно использовать `py` вместо `python`, а в Linux и macOS — `python3`.

Картинка из примера подойдёт для быстрой проверки. Для замера скорости лучше взять файл покрупнее. На маленьком файле большую часть времени может занять ожидание ответа сервера.

## Как считается результат

Скрипт засекает время перед запросом и останавливает таймер, когда прочитал файл до конца. Читает по 64 КиБ за раз и ничего не записывает на диск.

Чтобы получить среднее время запроса, скрипт складывает длительность десяти загрузок и делит на 10. Скорость считает по общему объёму в битах и суммарному времени в секундах. Один Мбит/с — это миллион бит в секунду.

Если сервер вернул ошибку, соединение оборвалось или сетевая операция превысила тайм-аут в 30 секунд, скрипт покажет номер запроса и завершится с кодом 1.
